Política de privacidade

Visus e Visus Clipper · atualizada em 20/11/2026

Este site

O site visusclipper.online apresenta os projetos Visus. Ele não usa cookies, não exibe anúncios e não utiliza ferramentas de rastreamento ou análise de visitantes. Os downloads e links levam a serviços externos (Google Drive e os sites de cada projeto), que têm suas próprias políticas.

Login no painel do Visus Clipper

O painel usa o login do Google apenas para identificar o usuário. Recebemos o e-mail, o nome e a foto do perfil, usados exclusivamente para liberar o acesso, exibir quem está conectado e registrar quem aprovou cada corte. Esses dados ficam armazenados no servidor do Visus Clipper e não são compartilhados com terceiros. A sessão é mantida por um cookie de login, necessário para o funcionamento do painel.

Google Drive

O Visus Clipper usa a permissão https://www.googleapis.com/auth/drive.file do Google Drive. Com ela, o app só consegue ver, criar e alterar os arquivos e pastas que ele mesmo criou (a pasta VisusClipper, com os cortes). Nenhum outro arquivo do Drive é acessado.

Como os dados são usados

  • Os cortes gerados são enviados ao Google Drive vinculado ao serviço e exibidos no painel aos usuários autorizados.
  • Após confirmar que os arquivos chegaram íntegros ao Drive, as cópias temporárias do servidor são apagadas.
  • Cortes podem ser excluídos pelo painel; nesse caso, vão para a lixeira do Google Drive.
  • Nenhum dado é vendido, compartilhado, usado para publicidade ou para treinar modelos de inteligência artificial.

Redes sociais

Quando contas de redes sociais são conectadas para publicação automática, as credenciais de acesso ficam somente no servidor do Visus Clipper e são usadas apenas para publicar os cortes aprovados.

Revogação e exclusão

O acesso do Visus Clipper à sua conta Google pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para solicitar a exclusão dos seus dados de login, escreva para o contato abaixo.

Uso de dados do Google (Uso Limitado)

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

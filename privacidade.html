Política de privacidade

Visus e Visus Clipper · atualizada em 20/11/2026

Este site

O site visusclipper.online apresenta os projetos Visus. Ele não usa cookies, não exibe anúncios e não utiliza ferramentas de rastreamento ou análise de visitantes. Os downloads e links levam a serviços externos (Google Drive e os sites de cada projeto), que têm suas próprias políticas.

Login no painel do Visus Clipper

O Visus Clipper é instalado no computador de cada usuário, e o painel roda nesse mesmo computador. Os dados de login (e-mail, nome, foto do perfil quando o login é feito com o Google, e senhas guardadas de forma cifrada) servem apenas para liberar o acesso, exibir quem está conectado e registrar quem aprovou cada corte. Eles ficam no computador onde o programa está instalado e não são enviados aos criadores do Visus Clipper nem a terceiros (veja a exceção do backup abaixo). A sessão é mantida por um cookie de login, necessário para o funcionamento do painel.

Google Drive

O Visus Clipper usa a permissão https://www.googleapis.com/auth/drive.file do Google Drive. Com ela, o app só consegue ver, criar e alterar os arquivos e pastas que ele mesmo criou (a pasta VisusClipper, com os cortes). Nenhum outro arquivo do Drive é acessado.

Como os dados são usados

  • Os cortes gerados são enviados ao Google Drive de quem instalou o programa e exibidos no painel às pessoas autorizadas por essa pessoa.
  • Após confirmar que os arquivos chegaram íntegros ao Drive, as cópias temporárias do computador são apagadas.
  • Cortes podem ser excluídos pelo painel; nesse caso, vão para a lixeira do Google Drive.
  • Cortes rejeitados na revisão são apagados de vez, do Drive e do computador, 2 minutos depois da rejeição. Até lá, a rejeição pode ser desfeita.
  • Nenhum dado é vendido, compartilhado, usado para publicidade ou para treinar modelos de inteligência artificial.

Redes sociais

O TikTok, o YouTube e o X podem ser conectados para publicação automática. Nesse caso, o acesso a essas contas fica no computador onde o programa está instalado e é usado apenas para publicar os cortes aprovados. Instagram, Facebook e Kwai são publicados manualmente pelo próprio usuário (o painel só oferece o vídeo e a legenda), a não ser que o usuário configure por conta própria a API oficial da Meta.

Backup no Google Drive

Se o usuário ligar o backup, as configurações do painel, as pessoas cadastradas, as contas conectadas, as sessões de login das redes, a fila e os canais são enviados para a pasta VisusClipper > _backup do próprio Google Drive do usuário. O arquivo vai criptografado (AES-256) com uma senha que só o usuário conhece; nem os criadores do Visus Clipper conseguem abri-lo. Nenhuma cópia do backup fica no computador, e os backups mais antigos são apagados automaticamente.

Revogação e exclusão

O acesso do Visus Clipper à sua conta Google pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados de login podem ser apagados a qualquer momento pelo dono do painel, em Acesso > Pessoas.

Uso de dados do Google (Uso Limitado)

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

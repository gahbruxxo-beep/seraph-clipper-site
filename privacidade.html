Política de privacidade

Seraph Clipper · atualizada em 19/11/2026

O que é

O Seraph Clipper é um aplicativo de uso pessoal que roda no computador do próprio usuário. Não existe servidor do Seraph Clipper: o app não envia dados para o desenvolvedor nem para terceiros.

Dados do Google acessados

Com a autorização do usuário, o app usa a permissão https://www.googleapis.com/auth/drive.file do Google Drive. Com ela, o app só consegue ver, criar e alterar os arquivos e pastas que ele mesmo criou (a pasta SeraphClipper com os clipes). Ele não tem acesso a nenhum outro arquivo do Drive.

Como os dados são usados

  • Os clipes gerados no computador do usuário são enviados para o Google Drive do próprio usuário.
  • O app confere se os arquivos chegaram inteiros e então apaga as cópias locais, para liberar espaço.
  • Nenhum dado do Google é vendido, compartilhado, usado para publicidade ou para treinar modelos de IA.

Armazenamento

O token de acesso fica somente no computador do usuário, no arquivo de configuração do app. Ele pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google (Limited Use)

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.
